## 1. 한글 파일 구조 요약

HWP 파일은 CFB(Compound File Binary) 구조를 가진다. 내부적으로 폴더의 역할을 하는 스토리지, 파일의 역할을 하는 스트림을 가진다.

> 📂 = 스토리지<br/>📄 = 스트림

**[표 2] 파일 전체 구조**

| 설명            | 구별 이름                                                               | 길이(바이트) | 레코드 구조 | 압축/암호화 |
| --------------- | ----------------------------------------------------------------------- | ------------ | ----------- | ----------- |
| 파일 인식 정보  | 📄 FileHeader                                                           | 고정         |             |             |
| 문서 정보       | 📄 DocInfo                                                              | 가변\*       | ✅          | ✅          |
| 본문            | 📂 BodyText<br/>├ 📄 Section0<br/>├ 📄 Section1<br/>└ 📄 ...            | 가변         | ✅          | ✅          |
| 문서 요약       | 📄 \005HwpSummaryInformation                                            | 고정         |             |             |
| 바이너리 데이터 | 📂 BinData<br/>├ 📄 BinaryData0<br/>├ 📄 BinaryData1<br/>└ 📄 ...       | 가변         |             | ✅          |
| 미리보기 텍스트 | 📄 PrvText                                                              | 고정         |             |             |
| 미리보기 이미지 | 📄 PrvImage                                                             | 가변         |             |             |
| 문서 옵션       | 📂 DocOptions<br/>├ 📄 \_LinkDoc<br/>├ 📄 DrmLicense<br/>└ 📄 ...       | 가변         |             |             |
| 스크립트        | 📂 Scripts<br/>├ 📄 DefaultJScript<br/>├ 📄 JScriptVersion<br/>└ 📄 ... | 가변         |             |             |
| XML 템플릿      | 📂 XMLTemplate<br/>├ 📄 Schema<br/>├ 📄 Instance<br/>└ 📄 ...           | 가변         |             |             |
| 문서 이력 관리  | 📂 DocHistory<br/>├ 📄 VersionLog0<br/>├ 📄 VersionLog1<br/>└ 📄 ...    | 가변         | ✅          | ✅          |

\* 공식 명세의 표 2는 `DocInfo` 길이를 “고정”으로 표시하지만, 같은 명세의 표 4는 `HWPTAG_FACE_NAME` 등 개별 레코드와 `DocInfo`의 전체 길이를 “가변”으로 표시한다. 이 표의 길이는 실제 스트림의 바이트 수를 뜻하므로 `가변`으로 바로잡았다.

### 채우기 정보 (그러데이션)

BorderFill 레코드에서 대각선 다음에 오는 채우기 정보 중, 실측으로 확정한 그러데이션 부분이다. 단색·이미지 블록은 아직 정리하지 않았다.

**[표 28] 채우기 정보 — 그러데이션 채우기(`type & 0x4`)일 때**

| 자료형        | 길이(바이트) | 설명                                                        |
| ------------- | ------------ | ----------------------------------------------------------- |
| UINT32        | 4            | 채우기 종류. 그러데이션만이면 `0x4`                         |
| UINT8         | 1\*          | 그러데이션 유형(표 30)                                      |
| INT32         | 4\*          | 기울임(시작 각)                                             |
| INT32         | 4\*          | 가로 중심                                                   |
| INT32         | 4\*          | 세로 중심                                                   |
| INT32         | 4\*          | 번짐 정도. `0`이면 그려지지 않는다\*\*                      |
| INT32         | 4\*          | 색 수(num)                                                  |
| INT32 × num   | 4 × num      | 색이 바뀌는 위치. num > 2일 때만(미확인)                    |
| COLORREF × num| 4 × num      | 색                                                          |
| UINT32        | 4            | 추가 채우기 속성 길이. 그러데이션이면 `1`                   |
| UINT8         | 1            | 번짐 중심                                                   |
| UINT8         | 1            | 알 수 없음\*\*\*                                             |

\* 공식 명세의 표 28은 유형부터 색 수까지 여섯 필드를 모두 INT16으로 적는다. 실제로는 유형이 1바이트, 나머지 다섯 필드가 4바이트다. 같은 값을 두 배치로 넣은 파일을 macOS용 한글 12.30.0(6544)에서 열었을 때, 이 배치는 속성 창에 값이 그대로 보였고 INT16 배치는 엉뚱한 값(검정·검정, 중심 100/0, 기울임 359)으로 읽혔다. 한글에서 직접 그러데이션을 지정해 저장한 파일도 이 배치와 바이트 구조가 같다.

\*\* 번짐 정도만 `0`, `50`, `255`로 바꾼 파일에서 `0`일 때만 셀이 칠해지지 않았다. 속성 창에는 값이 정상으로 보인다.

\*\*\* 공식 명세에 없는 바이트다. 채우기가 있으면 추가 채우기 속성 뒤에 1바이트가 붙고, 채우기 없음에는 없다. 한글이 저장한 파일에서는 단색·그러데이션·이미지 모두 `0`이었다. rhwp는 이 바이트를 투명도로 해석하고 켜진 종류마다 1바이트씩 읽지만, 이미지 채우기 파일에서 이 값만 `50`, `128`, `255`로 바꿔도 macOS용 한글의 표시가 원본과 같았다. 한글에는 셀 채우기 투명도 설정도 없다. 의미를 모르므로 원시 값만 보존한다.

예: 빨강→파랑, 기울임 90, 가로·세로 중심 0, 번짐 정도 255, 번짐 중심 50을 한글에서 지정해 저장한 레코드의 채우기 부분.

```text
04 00 00 00     채우기 종류: 그러데이션
01              유형
5a 00 00 00     기울임 90
00 00 00 00     가로 중심 0
00 00 00 00     세로 중심 0
ff 00 00 00     번짐 정도 255
02 00 00 00     색 수 2
ff 00 00 00     빨강
00 00 ff 00     파랑
01 00 00 00     추가 채우기 속성 길이 1
32              번짐 중심 50
00              알 수 없음
```
