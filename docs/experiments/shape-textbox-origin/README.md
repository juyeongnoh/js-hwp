# 글상자와 "도형 안에 글자 넣기"

한글의 그리기 도구에는 가로 글상자가 따로 있다. 사각형에서 오른쪽 클릭 → "도형 안에 글자 넣기"로도 글자가 든 도형을 만들 수 있다. 두 방법으로 만든 개체가 파일에서 같은지 확인했다.

- 날짜: 2026-11-24
- 환경: macOS용 한글(Hancom Office HWP, 파일 버전 5.1.1.0). computer use로 직접 조작했다.
- 파일: `textbox-and-shape-text.hwp`. 새 문서에 두 개체를 같은 크기로 끌어서 그렸다.
  1. 입력 → 도형 → 가로 글상자. 글자 `A`
  2. 입력 → 도형 → 사각형. 오른쪽 클릭 → 도형 안에 글자 넣기. 글자 `B`

## 결과

같다. 가로 글상자는 별도 개체가 아니라 글상자가 있는 사각형(`$rec`)이다.

| 레코드                                      | 다른 바이트                                                                               |
| ------------------------------------------- | ----------------------------------------------------------------------------------------- |
| CTRL_HEADER 60B                             | 세로 위치(오프셋 8), z-order(오프셋 24), 인스턴스 ID. 개체 설명문은 둘 다 "사각형입니다." |
| SHAPE_COMPONENT 252B                        | 채우기 뒤 인스턴스 ID만                                                                   |
| 글상자 LIST_HEADER 33B                      | 없음: `01000000 20000000 1b01×4 a7370000 00×13`                                           |
| PARA_HEADER, PARA_CHAR_SHAPE, PARA_LINE_SEG | 없음                                                                                      |
| PARA_TEXT                                   | 글자(`A`, `B`)만                                                                          |
| SHAPE_COMPONENT_RECTANGLE 33B               | 없음                                                                                      |

두 개체 모두 SHAPE_COMPONENT의 자식이 LIST_HEADER, PARA_HEADER, SHAPE_COMPONENT_RECTANGLE 순서다(정정 91). 코덱은 둘 다 `RectangleControl.textBox`로 읽는다.

## 세로 글상자

`vertical-textbox.hwp`는 위 파일에 입력 → 도형 → 세로 글상자(글자 `C`)를 더해 새 이름으로 저장한 것이다. 세로 글상자도 글상자가 있는 사각형(`$rec`)이고, 개체 설명문도 "사각형입니다."다. 가로 글상자와 다른 바이트는 위치·z-order·인스턴스 ID 말고 글상자 쪽뿐이다.

| 레코드 | 가로 (`A`) | 세로 (`C`) |
| --- | --- | --- |
| LIST_HEADER 리스트 속성 | `0x20` | `0x21`: bit 0~2 글자 방향 1(세로) |
| LIST_HEADER 텍스트 최대 폭 | `0x37a7` = 도형 폭 | `0x2183` = 도형 높이 |
| PARA_LINE_SEG | 줄 폭 `0x3570` | 줄 폭 `0x1f4c`, 오프셋 16도 다름(`0x0352` → `0x01f4`) |
| SHAPE_COMPONENT, 사각형 레코드 | 같음 | 같음 |

세로 글상자는 한글 메뉴에서 따로 고르는 도구지만, 파일에서는 가로 글상자에 글자 방향만 세로로 바꾼 것이다. 글상자의 최대 폭은 글이 흐르는 방향의 길이다. 가로면 도형 폭, 세로면 도형 높이다.

## 확인하지 않은 것

- 타원 등 다른 도형의 "도형 안에 글자 넣기".
- 오른쪽 클릭 메뉴의 "글상자 속성 없애기". 사각형에 글자를 넣기 전에는 비활성이었다.
