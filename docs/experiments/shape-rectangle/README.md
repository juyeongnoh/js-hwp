# 사각형 개체 속성(표 94)

명세 표 94는 SHAPE_COMPONENT_RECTANGLE을 모서리 곡률 BYTE, 사각형의 좌표 x INT32 4개, y INT32 4개(33바이트)로 적었다. 저장소 사각형은 모두 곡률 0이었고, 좌표가 x 4개, y 4개로는 맞지 않았다. 그래서 한글 개체 속성 "선" 탭의 "사각형 모서리 곡률"과 개체 크기를 바꿔 가며 저장했다.

- 날짜: 2026-11-24
- 환경: Windows용 한글 2024(파일 버전 5.1.2.0). 대화상자와 저장은 computer use로 직접 조작했다.
- 기반: `base.hwp`(`experiments/shape-fill/base.hwp`의 사본, 기본 사각형). 각 파일은 앞 파일에 이어서 바꿨다.
- 바꾼 곳: `BodyText/Section0`의 SHAPE_COMPONENT_RECTANGLE(SHAPE_COMPONENT의 자식)

| 파일 | 대화상자 | 곡률 | 꼭짓점(INT32 8개) | SHAPE_COMPONENT 처음 폭 / 현재 폭 |
| --- | --- | --- | --- | --- |
| `base` | 직각 | 0 | `0,0, 23134,0, 23134,15403, 0,15403` | 23134 / 23134 |
| `corner-round` | 둥근 모양 | 20 | 같음 | 같음 |
| `corner-half` | 반원 | 50 | 같음 | 같음 |
| `corner-35` | 곡률 지정 35% | 35 | 같음 | 같음 |
| `corner-35-width-100` | 리본에서 폭 100mm | 35 | 같음 | 23134 / 28345 |

- **꼭짓점은 (x, y) 쌍 4개다.** 왼쪽 위부터 시계 방향으로 (0, 0), (폭, 0), (폭, 높이), (0, 높이)다. 명세처럼 x 4개, y 4개로 읽으면 x가 `0, 0, 23134, 0`이 돼 맞지 않는다.
- **꼭짓점의 폭·높이는 개체를 만들 때의 크기다.** SHAPE_COMPONENT의 `initialWidth`, `initialHeight`와 같았다. 폭을 바꾸면 꼭짓점은 그대로이고 SHAPE_COMPONENT의 현재 폭(28345), 회전 중심 x(11567 → 14173), scale matrix(1.0 → 1.225296)만 바뀌었다. scale은 폭 비율 28345 / 23134 = 1.225253과 소수 다섯째 자리에서 달랐다.
- **곡률은 %이고 대화상자는 0~50만 받는다.** 곡률 지정에 80을 넣고 "설정"을 누르면 "0 ~ 50 % 사이의 숫자를 입력하세요"라며 받지 않았다.
- 저장소의 다른 사각형(`object-common-props`, `object-overlap-lock`, `fill-alpha` 등)도 꼭짓점이 처음 폭·높이의 (x, y) 쌍이었다. 처음 크기와 현재 크기가 다른 `rect-caption-bottom`(19298×13515 / 19300×13514)에서도 꼭짓점은 처음 크기였다.

## 확인하지 않은 것

- 50을 넘는 곡률을 넣은 파일을 한글이 어떻게 그리는지.
- 회전·반전한 사각형의 꼭짓점.
